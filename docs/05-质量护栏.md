# 05 · 质量护栏

出片容易，**出"看起来没问题"的坏片**更容易。这一节是流水线里所有自动校验的清单，
以及每条护栏对应的是哪一次事故。新增环节时，请同步在这里登记。

## 一、成片规格（写死在 `scripts/mix_final.py`）

| 项 | 规格 | 说明 |
|---|---|---|
| 分辨率 | 1080 × 1624 | 竖屏 2:3，数据与标题排版按此比例调过 |
| 帧率 | 30 fps | `FPS = 30` |
| 视频编码 | H.264 High / CRF 20 / yuv420p | |
| 声道 | **立体声（2）** | ⚠️ amix 会跟随第一个输入压成单声道，必须先 aformat |
| 采样率 | **48000 Hz** | ⚠️ loudnorm 会顶到 96k，后面必须 aresample=48000 |
| 响度 | -16 LUFS（`loudnorm=I=-16:TP=-1.5:LRA=11`） | |
| 时长 | 18 ~ 125 s（目标 `18 + 年度跨度 × 1.25`，封顶 105；另按数据点数封顶） | |

## 二、流水线内的自动校验

| 环节 | 护栏 | 触发后 | 对应事故 |
|---|---|---|---|
| `fit_narration.py` | 口播字数偏离目标 ±18% 才改写；改写结果 <60% 或 >160% 目标字数则丢弃保留原稿 | 保留原稿 | LLM 把稿子写残 |
| `tts.py` | 按 ≤220 字切块，逐块最多 4 次重试；每块校验「实测时长 vs 字数/4.8」，低于 55% 判失败 | 抛错，由 run.py 重试 | **TTS 静默截断**（踩坑 #11） |
| `run.py` | `vo_dur < 字数/4.8 × 0.6` → 重录 2 次，仍不达标**抛错拒绝成片** | 整支失败 | 同上 |
| `run.py` | `vo_dur > MAX_DUR` → 按 ≤1.35× 语速重录（不截断内容） | 加速重录 | 长题材超时 |
| `mix_final.py` | 混音后 `volumedetect` 平均音量 < -60 dB → **拒绝交付** | 抛错 | 混音静音 bug |
| `mix_final.py` | 声道/采样率不达标 → 打印 ✘（不阻断，历史片量大） | 告警 | 单声道事故（踩坑 #12） |
| `mix_final.py` | 配音与视频时长差 > 8 s → 告警 | 告警 | 头尾留白 |
| `deliver.py` | 归档 + manifest 登记，按 `(project, file)` 去重 | — | 重渲染产生重复编号 |

## 三、出片后的全量体检

```bash
# 体检默认目录 D:\AI视频\数据竞速
python tools/qa_delivered.py

# 连「TTS 截断」一起查（比对成片时长 vs 口播稿字数）
python tools/qa_delivered.py --narr-dir <ws>/data --slug2no <ws>/data/slug2no.json

# 落报告
python tools/qa_delivered.py --md 体检报告.md --json 体检.json
```

判定口径：

- **PASS** —— 时长、声道、采样率、音量、分辨率全部达标
- **WARN** —— 只有声道/采样率不达标，且文件是 `2026-09-16` 之前出的
  （老片是历史遗留，只在整批重渲染时一并修，不单独立项）
- **FAIL** —— 时长异常（<18s / >125s）、无音轨、疑似哑片（< -45 dB）、
  或成片时长 < 口播稿字数预期 × 0.6（TTS 截断）

退出码：0 = 无 FAIL；1 = 有 FAIL（可直接挂到批量任务的收尾）。

## 四、批量出片后的固定动作

```bash
python bin/race all --workspace ./workspace      # 1) 出片
python bin/race check --workspace ./workspace    # 2) 徽章英文/累计口径自检
python tools/qa_delivered.py --md 体检报告.md     # 3) 成片规格体检
```

三步都过了才算这一批能发。**不要跳过第 3 步** —— 前两步查的是数据和画面，
成片规格（声道/采样率/时长/哑片）只有第 3 步能发现。
