# 02 · 新增一个题材（5 分钟）

只改 `config/topics_registry.json`，不用写任何代码。

## 1. 准备数据

两条路：

**A. 用现成适配器**（推荐）—— 数据源在六条通道内（见 `docs/03-数据通道.md`）：

```jsonc
{
  "topics": [
    {
      "key": "my_topic",                    // 唯一标识，也是输出文件名
      "source": "wdi",                      // 适配器：csv|akshare_ashare|akshare_macro|wdi|owid|szse|nobel
      "params": {
        "indicator": "SP.POP.TOTL",         // 世行指标码
        "top": 15,
        "source": "世界银行 WDI"             // 画面右下角数据来源
      },
      "title": "各国人口竞速"
    }
  ]
}
```

**B. 直接喂 CSV**（最快）—— 任何渠道拿到的数据都行：

```jsonc
{
  "key": "my_topic",
  "source": "csv",
  "params": {
    "path": "data/my_topic.csv",            // 相对 workspace
    "mode": "rank",                          // rank=排名榜 | value=数值对比 | cumul=累计
    "title": "我的题材",
    "unit": "亿元",
    "decimals": 0,
    "source": "某某统计局"
  }
}
```

CSV 格式（**宽表，第一列是名称**）：

```
name,2015,2016,2017,2018
中国,100,120,140,165
美国,90,95,99,102
```

或**长表**（`year,value` 成对）：

```
name,year,value
中国,2015,100
中国,2016,120
```

## 2. 跑一支试试

```bash
python bin/race one --key my_topic --workspace ./workspace
```

只看不跑：`python bin/race list` 列出注册表全部题材。

## 3. 必须做的三件检查

```bash
python tools/check_badge_latin.py --workspace ./workspace   # 徽章无英文
python tools/scan_latin.py        --workspace ./workspace   # 画面文案无英文
python tools/check_cumulative.py  --workspace ./workspace   # 累计口径正确
```

常见要手工补的：
- 名称里带英文 → 加进 `scripts/entity_cn.py` 的映射表
- 单位带英文（TWh / GDP / ETF / CPI / Top10）→ 改成太瓦时 / 国内生产总值 / 指数基金 / 物价指数 / 前十
- 地区名「香港」→ 必须写成「中国香港」

## 4. 可调的细节

| 想改什么 | 改哪里 |
|---|---|
| 主题配色 | `scripts/run.py` 的 `THEME_RULES`（tech/pharma/energy/climate/military/…） |
| 背景画面 | `bg_prompt.py` 的 prompt；不满意就删缓存重生成 |
| 时长 | `fit_narration.py` 的 `BASE_SEC` / `SEC_PER_YEAR` / `MAX_DUR` |
| 成片编号 | `deliver.py --no NNN`（重渲染时用它覆盖原编号，不递增） |
