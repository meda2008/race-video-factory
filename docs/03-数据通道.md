## 必踩的坑

- **世行**：国家列表用 ISO3，数据行用 2 位码 → 必须用 `countryiso3code` 匹配。
- **世行 / OWID 都含聚合体** → 过滤 `region != 'Aggregates'` / `Code != 'OWID_WRL'`。
- **OWID 列名首字母大写**：`Entity` / `Code` / `Year`。
- **akshare 财报是长表**，按 `ITEM_NAME` 筛；**capex 为负数**要取绝对值；**财年错位**必须用 `REPORT_DATE`。
- **深交所两个坑**：广东被拆成「广东/深圳/广州」三行；西藏高企是**券商注册地口径**
  （东方财富、华林证券注册地在拉萨），真实但容易被误读成"西藏人爱炒股"。
- **诺奖 API 必须带 User-Agent**，否则 403。

## 数据契约

适配器统一返回：

```jsonc
{
  "years": ["2015", "2016", …],           // 字符串，支持 '1950Q4' / '2004-12'
  "industries": [
    { "name": "中国", "code": "CN",
      "values": { "2015": 100, "2016": 120 } }   // 字典；也兼容列表
  ],
  "meta": { "title": "…", "unit": "亿元", "mode": "rank",
            "decimals": 0, "legend": "…", "src": "…" }
}
```

⚠️ `values` **是字典不是列表** —— `build_race.py` 用 `it['values'].get(y)` 取值。
归一化时若拿到列表，`gen_timeline` / `fit_narration` 里有 `_val_at()` / `val_at()` 做兼容。

## 覆盖率护栏：用 Top-N 命中率，别用全表覆盖率

竞速只画 Top N 根柱子。判定某一年该不该保留，看**上一年 Top-N（默认 15）实体在新列还有值的比例**：

- 季度新增列：ratio ≥ 0.8
- 既有年度末列：ratio ≥ 0.6（优先保最新）

反例：`oil_production` 2025 全表只有 26% 上报，但 **Top15 命中 100%** → 该留；
美股 `2026Q3` 全表 40%，但 **Top10 只有 40%** → 该砍。
