# 01 · 架构与流水线

一支片从题材定义到成片，共 8 个阶段。每个阶段一个独立脚本，`scripts/run.py` 负责串起来。

```
 ┌─ 0. 题材定义 ────────────────────────────────────────────────┐
 │  config/topics_registry.json  {key, source, params, title…}   │
 └────────────────────────┬──────────────────────────────────────┘
                          ▼
 ┌─ 1. 取数 + 归一化 ───────────────────────────────────────────┐
 │  adapters/<source>.py  fetch(params) → 原始 JSON              │
 │  normalize_topic()     → {years, industries, meta}            │
 │  输出：data/topic_<slug>.json                                  │
 └────────────────────────┬──────────────────────────────────────┘
                          ▼
 ┌─ 2. 文案 ────────────────────────────────────────────────────┐
 │  gen_finance_meta.py --platform xhs|wechat                    │
 │  输出：titles / topics / desc / narration                     │
 │  ⚠ 有定制口播稿时先备份、生成后再还原                          │
 └────────────────────────┬──────────────────────────────────────┘
                          ▼
 ┌─ 3. 背景（内容相关） ────────────────────────────────────────┐
 │  bg_prompt.py   按标题/主题生成画面描述（LLM + 缓存）          │
 │  imgtable.gen_background() → 1620×2436 背景图                 │
 │  硬约束：暗调低饱和 + 中下部虚化留白 + 无文字                  │
 └────────────────────────┬──────────────────────────────────────┘
                          ▼
 ┌─ 4. 配音（时长由此确定） ────────────────────────────────────┐
 │  fit_narration.py  年度跨度 → 目标时长 → 目标字数 → LLM 改写   │
 │  tts.py --rate     Azure TTS / edge-tts → voiceover.mp3       │
 │  >120s 则提速重录（内容不截断，最快 1.35×）                    │
 └────────────────────────┬──────────────────────────────────────┘
                          ▼
 ┌─ 5. 画面 + 时间轴 ───────────────────────────────────────────┐
 │  gen_timeline.py  年度跨度 × 数据变化强度 → 锚点时刻            │
 │  build_race.py    --data --span --theme --bg-image --timeline  │
 │  输出：out/race.html                                           │
 └────────────────────────┬──────────────────────────────────────┘
                          ▼
 ┌─ 6. 逐帧渲染 ────────────────────────────────────────────────┐
 │  render_race.js（Playwright + Chromium）                      │
 │  输出：out/frames_topic_<slug>/f#####.jpg（30fps）             │
 └────────────────────────┬──────────────────────────────────────┘
                          ▼
 ┌─ 7. 混音 ────────────────────────────────────────────────────┐
 │  fetch_bgm.py  → BGM                                          │
 │  mix_final.py  → out/topic_<slug>.mp4（BGM + 配音 + 帧序列）   │
 └────────────────────────┬──────────────────────────────────────┘
                          ▼
 ┌─ 8. 交付 ────────────────────────────────────────────────────┐
 │  deliver.py --no NNN --outdir …                               │
 │  → D:\AI视频\数据竞速\NNN_标题.mp4 + _发布文案.md              │
 │  → 更新 manifest.json（按 project+file 去重）                  │
 └───────────────────────────────────────────────────────────────┘
```

## 各阶段关键参数

| 阶段 | 脚本 | 关键参数 | 说明 |
|---|---|---|---|
| 1 | `run.py` | `--key` / `--registry` | `--key '*'` 跑注册表全部题材 |
| 2 | `gen_finance_meta.py` | `--platform xhs\|wechat` | 两套文案分别生成 |
| 3 | `bg_prompt.py` | `--force` | 忽略缓存重新生成 |
| 4 | `fit_narration.py` | `BASE_SEC=18` `SEC_PER_YEAR=1.25` `MAX_DUR=105` <br>`SHORT_BASE_SEC=10` `SEC_PER_POINT=5` `MIN_SHORT_DUR=16` | 时长公式（年度跨度 + 数据点数双重封顶） |
| 4 | `tts.py` | `--rate` `CHUNK_CHARS=220` `MIN_OK_RATIO=0.55` | 1.0 正常，1.35 上限；分块合成防截断 |
| 5 | `gen_timeline.py` | `--no-densify` | 关闭变化强度加权 |
| 5 | `build_race.py` | `--span` `--theme` `--bg-image` | span=年度推进总时长 |
| 6 | `render_race.js` | `FRAMES_DIR` | 每题材独立帧目录 |
| 7 | `mix_final.py` | `--out` `--frames-dir` `--no-voice` | 输出固定 立体声 48k / -16 LUFS |
| 8 | `deliver.py` | `--no` `--outdir` `--kind` | `--no` 指定编号，不指定则递增 |

## 时长是怎么定下来的

```
年度跨度 = 末年 − 首年（标签前 4 位解析，支持 '2015' / '1950Q4' / '2004-12'）
目标时长 = clamp(18 + 年度跨度 × 1.25, 32, 105) 秒
         ↓ 数据点 ≤ 4 个时再按点数封顶（防止长时间定格）
         = min(目标时长, max(16, 10 + 5 × (数据点数 − 1)))
目标字数 = 目标时长 × 4.8    （中文播报实测 4.8~5.0 字/秒）
```

| 题材 | 年度跨度 | 数据点 | 目标时长 |
|---|---|---|---|
| 中国电影票房 | 15 年 | 15 | 37s |
| 中国各地股票交易额 | 22 年 | 22 | 46s |
| 各国贸易依存度 | 65 年 | 65 | 99s |
| 各国官方黄金储备 | 70 年 | 70 | 105s |
| 诺贝尔奖 | 124 年 | 124 | 105s（封顶） |
| 2026 大学排名 | 2 年 | **2** | **16s**（点数封顶生效） |
| 世界 500 强营收 | 10 年 | **3** | **20s**（点数封顶生效） |

口播稿偏离目标 ±18% 以内不动稿，超出才交给 LLM 改写（原稿备份 `*.orig`）。

> 数据点 ≤ 4 个的题材本质是「对比」不是「竞速」。点数封顶只是止血，
> 更好的做法是改用静态榜单图（方案 B `imgtable`）。

## 时间轴：为什么「不动的年份要快进」

画面推进速度 = 年度距离 × **数据变化强度权重**：

```
churn  = 0.6 × 名次变动比例 + 0.4 × 位移幅度
growth = 相邻两年数值相对变化
权重   = sqrt(0.08 + churn × 1.10 + growth × 0.80)
```

完全不动的区间塌到基线（≈0.28），剧变区间可达 1.25 —— 快慢差 1.4~4.4 倍。
口播锚点时刻**保持不变**，所以音画同步不受影响；所有区间权重相同时自动退化为匀速。

## 质检

| 工具 | 检查什么 |
|---|---|
| `tools/check_badge_latin.py` | 徽章不能出现 `CN-XX` / ISO2 / 英文国名 |
| `tools/scan_latin.py` | 画面文案残留英文（TWh / GDP / ETF / Top10…） |
| `tools/check_cumulative.py` | 累计口径是否真实累计（跨年比 0.9~1.35 为单期值） |
| `tools/qa_delivered.py` | **成片体检**：时长 / 声道 / 采样率 / 音量 / 分辨率 + TTS 截断 |
| `tools/rebuild_manifest.py` | 按磁盘真实文件重建项目清单（去重、补回填） |

前三项查**数据和画面**，第四项查**成片规格**——两类问题不重叠，批量出片后都要跑。
详见 [docs/05-质量护栏.md](docs/05-质量护栏.md)。
